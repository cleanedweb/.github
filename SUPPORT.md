# Getting help

- **Docs:** https://cleanedweb.com/docs/?utm_source=github&utm_medium=support
  ([Python](https://cleanedweb.com/docs/python/?utm_source=github&utm_medium=support),
  [JavaScript](https://cleanedweb.com/docs/javascript/?utm_source=github&utm_medium=support),
  [MCP](https://cleanedweb.com/docs/mcp/?utm_source=github&utm_medium=support),
  [Troubleshooting](https://cleanedweb.com/docs/troubleshooting/?utm_source=github&utm_medium=support))
- **Bug in an SDK or integration:** open an issue in that repository with the package version, a minimal
  reproduction and the error. Leave out API keys.
- **Account, billing, a run that returned the wrong records, or a site the catalog does not cover:** email
  info@cleanedweb.com with the API or run id.
- **Security issues:** see [SECURITY.md](SECURITY.md); do not open a public issue.
